# ringweave

**ringweave** is a zero-dependency TypeScript library that generates near-regular
graphs with minimal average shortest path length (ASPL): start with a ring,
greedily weave in chords between the farthest, least-connected vertices, then
optionally polish with degree-preserving edge swaps. Hard constraints
(required/prohibited edges) and soft constraints (preserve prior edges) are
supported.

**BuddyGraph** is the consumer product built on ringweave: give it a group of
people and a buddy count (say 3–4), and everyone gets an equal number of
buddies while the whole group stays as closely connected as possible — the
likely helper for any need is a buddy or a buddy-of-a-buddy. It runs entirely
client-side: no accounts, no backend, no roster ever leaves the device.

The split is deliberate: the package name serves library adopters (see
`docs/UPSTREAMING.md`), the product name serves organizers.

## What it does

Under the hood this builds a near-regular graph with small **average shortest
path length (ASPL)** — the mathematical target behind "everyone stays close to
everyone." The selected algorithm (see [`FINDINGS.md`](../docs/findings/FINDINGS.md)) is:

> **ring-greedy + incremental distance cache + degree repair**, with an optional
> fixed-seed **polish** pass at small sizes where it reaches provably-optimal
> ASPL cheaply.

Greedy is the spine — deterministic, explainable ("build a ring, add
connections greedily"), and incremental. Polish is an optional layer.

## Usage

```ts
import { buildBuddyGraph } from "ringweave";

const result = buildBuddyGraph(30, 4); // 30 people, 4 buddies each

result.buddies;   // number[][] — buddies[i] = person i's buddy indices
result.regular;   // true if everyone got exactly 4 buddies
result.aspl;      // average hops between any two people
result.diameter;  // worst-case hops
result.asplGap;   // fraction above the theoretical optimum (0 = optimal)
```

The same inputs always produce the same assignment (greedy is RNG-free; polish
uses a fixed seed).

## Development

```bash
npm install
npm test          # vitest: metrics, cross-language identity, pipeline
npm run typecheck # strict TS across src + tests
npm run build     # emits dist/ with .d.ts declarations
```

### Cross-language identity tests

`test/identity.test.ts` asserts that the TypeScript greedy produces
**byte-identical** edge sets to the original Python reference (fixtures in
`test/fixtures/reference.json`, generated by `gen_c_cached.ring_greedy_cached`).
Because greedy and repair use no randomness, this is a genuine cross-language
correctness proof, not an approximation.

## Layout

```
src/core/
  graph.ts     Graph container + ring seed
  metrics.ts   BFS distances, ASPL, diameter, girth, components
  bounds.ts    Moore lower bounds, ASPL gap, cycle ASPL
  greedy.ts    ring-greedy + incremental distance cache + degree repair
  polish.ts    degree-preserving double-edge-swap (hill / anneal)
  rng.ts       seeded deterministic RNG (mulberry32)
  index.ts     public API: buildBuddyGraph
test/
  metrics.test.ts    trust tests vs analytic references
  identity.test.ts   byte-identity vs Python
  pipeline.test.ts   public API + polish invariants
```
